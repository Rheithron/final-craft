# Final Craft

Final Craft is an Obsidian plugin for compiling screenplays from Markdown notes.

## Current status

The P0 foundation registers **Final Craft: Compile screenplay**. Run it from an
active Markdown note to confirm that Final Craft can read the note. Screenplay
parsing, pagination, preview, and PDF rendering are not implemented yet.

## Development

```bash
npm install
npm run build
npm run lint
```
